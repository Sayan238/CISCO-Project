CASE ID: NET-003

TITLE:
VLAN 30 Missing

SYMPTOM:
The device connected to Switch Fa0/3 cannot communicate with the VLAN 30 gateway.

TOPOLOGY:
Device/Server1 -> Switch0 Fa0/3 -> Switch0 Fa0/4 -> Router0

EXPECTED VLAN:
VLAN 30 - SERVER

EXPECTED PORT:
FastEthernet0/3

EXPECTED CONFIGURATION:
Fa0/3 should be an access port assigned to VLAN 30.

FAULT INTRODUCED:
VLAN 30 was deleted from Switch0.

FAULT COMMAND:
no vlan 30

EVIDENCE COMMAND:
show vlan brief

EVIDENCE:
Before the fault:
VLAN 30 SERVER was active and Fa0/3 was assigned to VLAN 30.

After the fault:
VLAN 30 SERVER is missing from the VLAN table.

Current VLANs:
VLAN 10 STUDENT - active - Fa0/1
VLAN 20 STAFF - active - Fa0/2
VLAN 30 SERVER - MISSING

TRUNK EVIDENCE:
Command:
show interfaces trunk

Fa0/4 is still operating as a trunk.

Fa0/4:
Mode: on
Encapsulation: 802.1q
Status: trunking
Native VLAN: 1

VLANs allowed on trunk:
1-1005

VLANs allowed and active:
1,10,20

IMPORTANT:
VLAN 30 is not present because VLAN 30 has been deleted.

RUNNING CONFIG EVIDENCE:
interface FastEthernet0/3
 switchport access vlan 30
 switchport mode access

The Fa0/3 configuration still references VLAN 30, but VLAN 30 itself no longer exists.

EXPECTED FAULT:
VLAN 30 has been deleted from Switch0.

OSI LAYER:
Layer 2

CONCEPT:
VLAN

SEVERITY:
High

EXPECTED NEXT COMMAND:
show vlan brief

EXPECTED FIX:
Recreate VLAN 30 and assign Fa0/3 to VLAN 30.

FIX COMMAND:
configure terminal
vlan 30
name SERVER
interface fastEthernet 0/3
switchport mode access
switchport access vlan 30
end

EXPECTED RESULT AFTER FIX:
VLAN 30 should appear as active.
Fa0/3 should appear under VLAN 30.
VLAN 30 should become active on the trunk.
