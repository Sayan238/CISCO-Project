CASE ID: NET-005

TITLE:
Access Port in Trunk Mode

SYMPTOM:
The device connected to Switch0 Fa0/3 cannot communicate correctly with VLAN 30.

TOPOLOGY:
Device/Server1 -> Switch0 Fa0/3 -> Switch0 Fa0/4 -> Router0

EXPECTED VLAN:
VLAN 30 - SERVER

EXPECTED PORT:
FastEthernet0/3

EXPECTED CONFIGURATION:
Fa0/3 should be an access port assigned to VLAN 30.

FAULT INTRODUCED:
FastEthernet0/3 was incorrectly configured as a trunk port.

FAULT COMMAND:
interface fastEthernet 0/3
switchport mode trunk

EVIDENCE COMMAND:
show interfaces trunk

EVIDENCE:

Fa0/3 is incorrectly operating as a trunk.

Fa0/3:
Mode: on
Encapsulation: 802.1q
Status: trunking
Native VLAN: 1

VLANs allowed on Fa0/3:
1-1005

Fa0/3 should not be a trunk because it is the server/device access port for VLAN 30.

VLAN TABLE EVIDENCE:
Command:
show vlan brief

VLAN 30 SERVER is active, but Fa0/3 is not listed under VLAN 30.

VLAN 30:
SERVER - active

Fa0/3 is missing from the VLAN 30 port list because the interface is operating as a trunk.

IMPORTANT:
Fa0/4 is the correct trunk port connecting Switch0 to Router0.

Fa0/4:
Mode: on
Encapsulation: 802.1q
Status: trunking

EXPECTED FAULT:
Switch0 Fa0/3 is configured as a trunk instead of an access port.

OSI LAYER:
Layer 2

CONCEPT:
Access Port / Trunking / VLAN

SEVERITY:
High

EXPECTED NEXT COMMAND:
show interfaces trunk

EXPECTED FIX:
Change Fa0/3 back to an access port and assign it to VLAN 30.

FIX COMMAND:
configure terminal
interface fastEthernet 0/3
switchport mode access
switchport access vlan 30
end

EXPECTED RESULT AFTER FIX:
Fa0/3 should operate as an access port.
Fa0/3 should be assigned to VLAN 30.
Fa0/3 should no longer appear in show interfaces trunk.
VLAN 30 should show Fa0/3 under the Ports column.
